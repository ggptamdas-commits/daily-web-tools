## 🌟 Features

- 🔒 **100% Client-Side & Private**: All conversions, hashes, and formatting run directly in your browser. No data ever leaves your computer.
- ⚡ **Zero Dependencies / Blazing Fast**: Built with pure vanilla JavaScript, modern Web APIs, and Tailwind CSS.
- 🌓 **Dark & Light Mode**: Seamless dark mode support with system preference detection and localStorage persistence.
- 📱 **Mobile-First & Responsive**: Clean Bento-grid layout, keyboard shortcuts (`/` for search, `Esc` to close modal).
- ⭐ **Favorites & Quick Search**: Star your most-used tools and find any utility instantly with real-time filtering.
- 🔄 **Continuous Daily Additions**: Automatically updated daily with new web tools, helpers, and utilities.

| Tool | Category | Description |

## 🚀 How to Deploy on Vercel

1. **One-Click Deploy**:
   Click the **[Deploy with Vercel](https://vercel.com/new/clone?repository-url=https%3A%2F%2Fgithub.com%2Fggptamdas-commits%2Fdaily-web-tools)** button above.
2. **Manual Import**:
   - Go to [Vercel Dashboard](https://vercel.com/dashboard).
   - Click **Add New** → **Project**.
   - Select the `ggptamdas-commits/daily-web-tools` repository.
   - Framework Preset: **Other** (Static HTML).
   - Click **Deploy**! Your site is live in seconds with HTTPS.
